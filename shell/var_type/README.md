Shell 中所有变量本质上都是字符串，没有真正的"数值类型"。

 在 Shell 中，以下三种写法结果一样：
 ```
A=10
A="10"
A='10'
 ```
赋值后，A 的内容都是字符串 "10"。Shell 没有编译时的类型检查，变量在赋值时不会做类型转换，只是存字符串。


Shell 只有在算术运算上下文中，才会把字符串临时解析为整数：
```
A="10"
B="2"

# 算术扩展：$(( )) 内部会把字符串当数字解析
echo $((A + B))    # 输出 12

# 但字符串拼接/比较时，它仍然是字符串
echo "$A$B"        # 输出 "102"（字符串拼接）
[ "$A" \> "$B" ]   # 字符串比较：按字典序，"10" < "2"（因为 '1' 的 ASCII 码 < '2'）

declare -i A=10
declare -p A       # 输出：declare -i A="10"

A="10" + "2"       # 错误！declare -i 只影响算术赋值语法
A=10+2             # 赋值时自动做算术运算，A 变成 12
```
