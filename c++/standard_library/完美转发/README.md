# 完美转发

## 1、简介
参考：https://mp.weixin.qq.com/s/CKJvlDjzgh5PoHDheZmeRg
混淆万能引用与右值引用：在任何地方看到 T&& 都认为是右值引用。错误！ 只有在发生模板类型推导的上下文中，T&& 才是万能引用。

## 2、实战应用场景
std::vector::emplace_back, std::map::emplace 等方法是完美转发的典型应用。它们直接在容器内存中构造对象，而不是先创建临时对象再拷贝或移动。

“std::move 和 std::forward 有什么本质区别？分别在什么场景下使用？”
思路：std::move 是 无条件 将其参数转换为右值，代表着你明确希望转移其资源所有权，原对象此后应处于“有效但未指定”的状态。它用于移动语义的实现。std::forward 是 有条件 转换，仅当其参数原本是右值时才转换为右值，目的是保持参数原有的值类别。它用于泛型编程中的转发。

“decltype(auto) 和完美转发有什么关系？”
思路：decltype(auto) 用于函数返回类型的推导，它能精确地推导出表达式的值类别。当一个泛型函数需要将其内部调用的另一个函数的返回结果原封不动地返回时（包括值类别），就需要 decltype(auto)。这可以看作是“返回值的完美转发”。

“除了函数模板，完美转发还能用在哪些地方？”
思路: 泛型Lambda表达式。从C++14开始，Lambda表达式的参数可以使用 auto。auto&& 参数同样是万能引用，可以配合 std::forward 实现完美转发。
