# 二叉树
在计算机科学中，树是一种抽象数据类型（ADT）或是实现这种抽象数据类型的数据结构，用来模拟有层次的或树状的结构。在树的定义中，有一个被称为“根”的特定元素，其他元素被称为“节点”，每个节点都有0个或多个子节点。

## 1、分类
二叉树（Binary Tree）：每个节点最多有两个子节点，通常称为左子节点和右子节点。二叉树是最常见的树形结构之一，许多其他类型的树可以视为二叉树的特例或扩展。

完全二叉树（Complete Binary Tree）：除最后一层外，其他层的节点数达到最大，且最后一层的节点尽可能集中在左侧。完全二叉树在某些算法中具有重要应用。

平衡二叉树（Balanced Binary Tree）：任何节点的两个子树的高度差不超过1。平衡二叉树在插入、删除节点时能保持相对平衡，从而提高算法效率。

AVL树（Adelson-Velsky和Landis发明）：平衡二叉树的一种，任何节点的两个子树的高度差最多为1。AVL树是最早的平衡二叉树之一。

红黑树（Red-Black Tree）：一种自平衡的二叉查找树，通过节点颜色（红或黑）和特定规则来维护平衡。红黑树在插入、删除节点时能保持相对平衡，并具有较低的查找时间复杂度。

红黑树不属于任何b-、b+和b\*树，后者都是节点大于2的树。
