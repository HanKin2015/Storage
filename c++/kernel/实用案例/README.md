## 1. cmake编译
在 Linux 环境下，内核驱动通常依赖内核自带的 Kbuild 系统编译，但可以通过 CMake 作为 “胶水” 工具来整合构建流程（本质上仍是调用 Kbuild 完成驱动编译）。这种方式适合需要将驱动代码与其他 CMake 管理的项目（如应用程序、库）整合的场景。

Kbuild 是内核模块的编译规则文件，CMake 会间接调用它。

为什么需要 Kbuild：Linux 内核模块编译依赖内核源码中的宏定义、配置和构建规则，Kbuild 是内核原生支持的构建系统，CMake 仅作为 “协调者” 调用它。
