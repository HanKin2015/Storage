# 类模板

## 1、简介
类模板（Class Template）是 C++ 中实现泛型编程的重要工具，它允许创建通用的类定义，其中的部分类型或值可在实例化时动态指定。通过类模板，你可以编写与具体数据类型无关的代码，提高代码复用性。

核心概念
- 参数化类型：类模板定义中使用类型参数（如 typename T）代替具体类型。
- 实例化：使用时需指定具体类型，编译器会自动生成对应类的代码。
- 泛型设计：适用于容器、算法、智能指针等需要处理多种数据类型的场景。

## 2、全特化
在 C++ 中，全特化（Full Specialization） 是模板编程的一项重要特性，允许为模板的特定参数值提供定制化的实现。当通用模板对某些特殊类型或值不适用时，可以通过全特化提供专门的代码逻辑。

## 3、函数模板特化 vs 重载
全特化：保持模板接口，仅替换实现。
函数重载：定义新函数，可能有不同参数或返回类型。

## 4、部分特化
类模板可进行部分特化（如 template <typename T> class Container<T*>），但函数模板不支持。

## 5、模板元编程
模板元编程（Template Metaprogramming, TMP）是 C++ 中一种特殊的编程技术，它利用编译器处理模板的过程执行计算，在编译期生成代码，而非在运行时执行。TMP 将计算从运行时转移到编译期，可显著提升程序性能，并实现类型安全和代码优化。

## 6、元编程和模板元编程
在 C++ 的语境中，元编程（Metaprogramming）和模板元编程（Template Metaprogramming, TMP）是相关但不同的概念：

- 元编程是一种编程范式，其核心是编写程序来生成或操纵其他程序。它的目标是让代码在运行前（编译期）或运行时自动完成某些任务，从而减少重复代码、提高灵活性或优化性能。
- 模板元编程（TMP）是 C++ 中实现元编程的主要技术，它利用 C++ 的模板系统在编译期执行计算、生成代码或操作类型。TMP 将计算从运行时转移到编译期，典型应用包括编译期常量计算、类型特性判断和代码生成。
元编程的其他实现方式

虽然 TMP 是 C++ 中最常用的元编程技术，但元编程还可以通过其他方式实现：
1. 预处理器元编程
使用 C++ 预处理器（宏）在编译前进行文本替换和代码生成

2. 运行时元编程
通过反射（如 C++20 的std::type_info）或动态加载（如dlopen）在运行时操作程序结构

3. 编译器插件
通过自定义编译器插件（如 Clang 插件）在编译过程中修改 AST（抽象语法树）

C++ 中的元编程演进
C++98/03：主要依赖模板元编程（如std::iterator_traits）。
C++11/14：引入constexpr、可变参数模板，简化 TMP。
C++17：引入if constexpr、折叠表达式，增强编译期逻辑。
C++20：引入概念（Concepts）、编译期反射实验性支持。
C++23/26：计划增强元编程能力（如模板参数包展开改进）。
