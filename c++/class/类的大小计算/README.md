# 类的大小计算
C++ 类的大小（即类实例化后的对象所占用的内存大小）由多个几个核心因素决定，遵循 “只计算实际存储的数据，忽略成员函数” 的基本原则，同时特殊情况（如虚函数、继承）会影响最终大小。

## 1、非静态成员变量的大小总和
类的大小首先由所有非静态成员变量的大小决定，静态成员变量不计算在内（静态成员属于类本身，存储在全局区，而非对象中）。
## 2、内存对齐（Padding）
为了提高 CPU 访问效率，编译器会对成员变量进行内存对齐（按一定规则在成员间插入空白字节），这会导致类的实际大小可能大于成员变量的总和。

对齐规则通常遵循：
- 每个成员的起始地址是其自身大小的整数倍；
- 整个类的大小是其最大成员大小的整数倍。

## 3、虚函数（引入虚函数表指针）
如果类中包含虚函数（或继承了包含虚函数的类），编译器会为类添加一个虚函数表指针（vptr），用于实现多态。
- 虚函数表指针的大小为 4 字节（32 位环境）或 8 字节（64 位环境）；
- 无论类中有多少个虚函数，都只需要一个虚函数表指针。

## 4、继承关系
派生类的大小 = 基类成员变量的大小 + 派生类新增成员变量的大小（同样受对齐和虚函数影响）。
（1）普通继承（无虚函数覆盖）
基类的成员变量会被派生类继承，计入派生类大小。

（2）虚继承（解决菱形继承的冗余问题）
虚继承会引入虚基类指针（vbptr） 或偏移量，用于定位虚基类成员，避免数据冗余。这会增加派生类的大小（通常 4 或 8 字节）。

## 5、空类的特殊情况
空类（无任何成员变量和虚函数）的大小为 1 字节（编译器为了区分不同的空类对象，会分配 1 字节的占位空间）。
若空类继承自另一个空类，其大小仍为 1 字节（编译器优化掉冗余的占位）。
